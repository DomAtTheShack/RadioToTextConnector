Radio to Text Connector - apt packages needed (Ubuntu / WSL)
============================================================

Install everything at once:

    sudo apt update
    sudo apt install build-essential cmake ninja-build gdb pkg-config autoconf automake \
        libasound2-dev libsndfile1-dev libfftw3-dev libpulse-dev libsndio-dev \
        libusb-1.0-0-dev libudev-dev libgpiod-dev \
        alsa-utils libasound2-plugins pulseaudio-utils


What each one is for
--------------------

Building Radio to Text Connector (CMakeLists.txt)
    build-essential      g++, make and the C/C++ standard headers
    cmake                CMakeLists.txt asks for CMake 4.1 or newer
    ninja-build          Build tool CLion uses by default
    gdb                  Debugger for CLion
    libasound2-dev       ALSA headers + library (alsa/asoundlib.h, find_package(ALSA))
    libusb-1.0-0-dev     Only for -DRTC_STATIC=ON: what a static Hamlib links
    libudev-dev          against (libusb, and libudev, which libusb uses)

Building minimodem (minimodem/install-dependencies-linux.sh)
    pkg-config           Lets ./configure find the libraries below
    autoconf, automake   Generate ./configure (autoreconf -i)
    libfftw3-dev         FFT library minimodem decodes with (required)
    libsndfile1-dev      Reading .wav files (RadioConnectorCli file.wav)
    libasound2-dev       ALSA input (--alsa=...)
    libpulse-dev         PulseAudio input (minimodem's default under WSLg)
    libsndio-dev         sndio input (optional, script installs it)

Building direwolf (direwolf/CMakeLists.txt)
    libasound2-dev       ALSA sound cards
    libudev-dev          CM108 USB sound card PTT (optional)
    libgpiod-dev         GPIO PTT on a Raspberry Pi (optional)
    Hamlib               For CAT PTT: build Hamlib first (`make install`), and
                         direwolf's cmake picks it up from /usr/local

Audio under WSL
    alsa-utils           arecord / aplay, to test the mic:  arecord -D default -d 5 test.wav
    libasound2-plugins   ALSA "pulse" plugin, so ALSA "default" reaches the Windows mic via WSLg
    pulseaudio-utils     pactl, to check what WSLg exposes:  pactl list sources short


Building minimodem after the packages are installed
---------------------------------------------------

    cd minimodem
    autoreconf -i
    ./configure
    make
    sudo make install        # installs /usr/local/bin/minimodem, the path main.cpp runs


Building direwolf after the packages (and Hamlib) are installed
---------------------------------------------------------------

    git clone --branch 1.8.1 https://github.com/wb2osz/direwolf.git
    cd direwolf && mkdir build && cd build
    cmake ..                 # check it says "Found hamlib", or CAT PTT won't work
    make -j"$(nproc)"
    sudo make install        # installs direwolf, atest and gen_packets in /usr/local/bin

Or simply `sudo apt install direwolf`: Ubuntu's package is built with Hamlib too.
